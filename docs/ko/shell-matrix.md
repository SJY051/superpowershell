# 셸 매트릭스

이 환경은 하나의 셸만 있는 단순한 구조가 아닙니다.

## 현재 커버리지 스냅샷

| 셸 | 역할 | 버전 | 비고 |
| --- | --- | --- | --- |
| `pwsh` | 기본 interactive / agent 셸 | 7.5.x 이상 | 가장 풍부한 프로필 동작과 주 대상 |
| `powershell` | 호환성 셸 | 5.1 | 호환용으로 유지, 주 UX 대상은 아님 |
| `wsl:sh` | 부분적 Unix fallback | 현재 스냅샷에서 버전 미상 | 진짜 POSIX 의미론이 필요할 때 유용 |

## 실전 가이드

- 일상 작업은 `pwsh`
- 오래된 모듈이나 호환성 제약이 있을 때만 Windows PowerShell 5.1
- 셸 의미론이 중요할 때는 WSL

## 에이전트에게 왜 중요한가

에이전트는 이 환경의 모든 셸이 동일하게 동작한다고 가정하면 안 됩니다.

- alias가 다르고
- 프로필 로딩이 다르고
- 모듈 지원이 다르고
- 시작 부작용도 다릅니다

그래서 “다 똑같다”는 전제를 두기보다 차이를 문서화하는 편이 훨씬 안전합니다.
