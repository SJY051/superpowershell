# Windows 친화 에이전트를 위한 재사용 가능한 스킬 범주

에이전트 프레임워크가 스킬, 프롬프트, 플레이북, 레시피 같은 재사용 가능한 단위를 지원한다면, Windows 환경은 그 가치를 특히 크게 느끼기 쉽습니다.

## 유용한 범주

### 디버깅 규율

다음 흐름을 강제하는 스킬이 좋습니다.

- 증상 수집
- 재현
- 근거 수집
- 수정 전에 근본 원인 추적

### 검증 규율

관련 명령, 테스트, 관찰 가능한 결과를 실제로 확인하기 전에는 작업을 완료라고 말하지 않는 규칙을 스킬로 고정하는 편이 좋습니다.

### 리뷰 체크포인트

언제 리뷰를 걸지, 어떤 범위를 볼지, 어떤 형식으로 결과를 정리할지를 잡아 주는 스킬이 유용합니다.

### 제한된 위임

서브에이전트가 있다면, 언제 허용할지, 어떤 출력 형식을 기대할지, 어떤 판단이 메인 스레드에 남아야 하는지를 명시하는 스킬이 도움이 됩니다.

### 문서화와 웹 정리

Windows 중심 환경에서는 다음 같은 작업도 스킬로 고정하기 좋습니다.

- 웹 문서를 깔끔한 텍스트로 추출
- 셸 차이를 더 분명하게 문서화
- 로컬 특성을 반복 가능한 절차로 정리

## 왜 Windows에서 특히 중요한가

Windows는 다음 이유로 더 명시적인 운영 지식이 필요합니다.

- POSIX 셸과 명령 의미가 다를 수 있음
- 별칭 뒤에 PowerShell 특유 동작이 숨어 있을 수 있음
- 설치 경로와 설치 방식이 더 다양함
- 프로필 잡음과 시작 부작용이 비교적 흔함

재사용 가능한 스킬은 이런 지역적 사실을 매번 다시 배워야 하는 부담을 줄여 줍니다.
