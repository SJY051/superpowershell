# 에이전트 빠른 시작

이 문서는 로컬 코딩 에이전트가 차분한 Windows 셸을 빠르게 갖추기 위한 가장 짧은 경로를 정리합니다.

## 목표

에이전트에게 다음을 제공하는 것입니다.

- 예측 가능한 기본 셸
- 낮은 시작 잡음
- 역할이 분명한 대표 명령 집합
- 파일, 데이터, HTTP 응답을 추측 없이 다룰 수 있는 구조화 도구

## 권장 최소 구성

1. `pwsh` 7.5 이상 설치
2. [install.md](install.md)의 핵심 베이스라인 설치
3. 에이전트용 저잡음 실행 프로필 준비
4. `tools` 같은 도구 레지스트리 노출
5. 겹치는 도구 중 대표 명령을 명확히 지정

## 대표 명령 집합

- 텍스트 검색: `rg`
- 파일 탐색: `fd`
- 파일 보기: `bat`
- JSON 처리: `jq`
- YAML 처리: `yq`
- 디렉터리 listing: `eza`
- 디렉터리 점프: `zoxide`
- 작업 실행: `just`
- 기본 HTTP: `curl`
- 읽기 좋은 HTTP 보조: `xh`

## 좋은 기본값

- 정말 깨끗한 기준선이 필요할 때는 `pwsh -NoLogo -NoProfile`
- 안정적이면서 조금 더 풍부한 환경이 필요할 때는 별도 execution profile
- alias는 반드시 문서화
- 구조화 출력 도구는 쉽게 찾을 수 있게 노출
- 진짜 POSIX 의미론이 필요할 때만 WSL을 우선 사용

## 피할 것

- 거대한 단일 PowerShell 프로필
- 자동화 맥락에서 장식성 시작 잡음
- 대표 명령이 없는 중복 기본값
- 문서화되지 않은 wrapper나 alias
